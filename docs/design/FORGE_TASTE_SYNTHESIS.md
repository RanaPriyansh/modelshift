# FORGE Taste Synthesis

Status: Recommended design direction.

Date: 2026-08-01.

Source set: `IMG_1136.JPG` to `IMG_1141.JPG`, `IMG_1394.JPG` to `IMG_1409.JPG`, and `IMG_1410.JPG` to `IMG_1412.JPG`.

## 1. Direction

The recommended middle ground is:

> Vivid at thresholds. Quiet during work.

The design system remains **FORGE Terrain**.

The visual direction remains **Vivid Learning Landscapes**.

The public site uses expressive editorial art.

The web application uses clear product structure.

Protected proof uses a neutral and explicit work surface.

The iOS application uses native Apple structure.

## 2. Reference families

The reference set contains two related design families.

### 2.1 Expressive editorial art

This family includes:

- Saturated landscape color.
- Surreal architecture and terrain.
- Grain, halftone, screen print, CRT blur, and pixel artifacts.
- Large poster typography.
- One small person, boat, house, bench, animal, path, or doorway.
- Large fields of sky, water, grass, or shadow.

This family creates curiosity and identity.

Use this family at public entry, path entry, return, and major transitions.

### 2.2 Clear scenic product design

This family includes:

- Thin navigation.
- Short headlines.
- One primary action.
- Strong negative space.
- A full landscape hero.
- Clear product surfaces below the hero.

This family creates comprehension and task focus.

Use this family for navigation, forms, attempts, repair, sources, and evidence.

## 4. Controlled intensity

FORGE uses one identity with four intensity levels.

| Surface | Variance | Motion | Density | Art use |
| --- | ---: | ---: | ---: | --- |
| Public site | 8 | 5 | 3 | Full hero and two supporting image plates |
| Web application | 5 | 3 | 5 | Today, path entry, return, and major transitions |
| Protected proof | 2 | 1 | 4 | No environmental art |
| iOS application | 4 | 3 | 4 | Cropped headers on onboarding, Today, and Return |

These values are design review dials.

They are not product metrics.

## 5. Public site

Use the strongest visual expression on the public site.

- Use one full hero landscape.
- Use a short large headline.
- Use one compact orange action.
- Use thin navigation.
- Use asymmetric editorial sections.
- Use two supporting image plates on a long page.
- Keep grain inside imagery.
- Keep body content on solid surfaces.

Do not use a generic three-card feature row.

Do not copy a reference brand or a distinctive composition.

## 6. Web application

Use a restrained expression in the web application.

- Use Field surfaces during attempts and repair.
- Use Ledger surfaces for sources and evidence.
- Keep one dominant action.
- Use orange only for a learner commitment.
- Use blue only for a disclosed system or AI contribution.
- Use green only for reviewed evidence.
- Use spacing before a border.
- Use mono type only for evidence and source identifiers.

Do not place dense learning content over a landscape.

Do not use a chat interface as the main application structure.

## 7. Protected proof

Protected proof must be visually quiet.

- Remove environmental art.
- Remove decorative motion.
- Keep access support visible.
- Show one task.
- Show one submission action.
- Show evidence limits.
- Show the assistance boundary.

Do not use playful art, large poster type, or reward signals.

## 8. iOS application

Use native Apple structure and behavior.

- Use SF Pro and Dynamic Type.
- Use native navigation, tab bars, sheets, alerts, and controls.
- Use terrain art as a header.
- Keep controls on a solid surface.
- Use system motion.
- Use one haptic for a meaningful commitment.
- Support Reduce Motion.

Do not place controls over complex art.

Do not reproduce web navigation inside the iOS application.

## 9. Typography

Use Geist as the stable web family.

Use Geist Mono for short technical identifiers.

Use Libre Baskerville only for a brief learner reflection.

Use SF Pro through native text styles on iOS.

Use pixel type only for campaign posters, world covers, or special transitions.

Do not use pixel type for controls, instructions, forms, or evidence.

## 10. Image language

Use surreal pastoral scenes with editorial composition.

Prefer these subjects:

- A path.
- A doorway.
- A tool.
- A boat.
- A bridge.
- A small shelter.
- A small learner.
- A quiet animal.

Use simple geometry and strong silhouette.

Use separate text-safe crops for desktop, mobile, light, and dark themes.

Do not use a mountain summit as a mastery symbol.

Do not use stock photographs of students.

Do not use a persistent tutor mascot.

## 11. Motion

Motion must explain state or causality.

- Reveal a scene with a slow crop or mask.
- Move interface items by no more than 24 pixels.
- Use a route line only when the route changes.
- Use short dissolves for state changes.
- Remove decorative motion when Reduce Motion is active.

Do not use continuous parallax, animated grain, reward bursts, or repeated completion pulses.

## 12. Ethical motivation

Create satisfaction through capability and closure.

- Show one useful next action.
- State why the action matters.
- Give immediate and specific feedback.
- Show a visible repair route.
- Show what changed.
- Show what remains open.
- Give permission to stop.
- Prepare a later return with a new case.

Do not describe the product as addictive.

Do not use points, streaks, badges, ranks, variable rewards, shame, or notification pressure.

## 13. Preserved decisions

Keep these decisions:

- `FORGE Terrain`.
- `Vivid Learning Landscapes`.
- Horizon, Field, Ledger, and Threshold.
- Cobalt, forest, orange, ivory, and midnight.
- The orange doorway.
- The trust line.
- Light, Dark, and System themes.
- The Recall, Attempt, Repair, Prove, and Return learning loop.

## 14. Refinements

Apply these refinements:

- Reduce uppercase mono eyebrow labels.
- Keep mono type for evidence and source identifiers.
- Add controlled image rhythm below the public hero.
- Keep orange actions for commitments.
- Use ink or outline actions for navigation and inspection.
- Keep Libre Baskerville for brief reflection.
- Limit unusual type to campaigns, covers, and transitions.
- Keep playful animals outside evidence and proof surfaces.

## 15. Review test

A design matches this taste model when:

1. One action has clear visual priority.
2. The scene has one agency marker.
3. Texture does not reduce text clarity.
4. Active work uses a quiet surface.
5. Color meaning includes text or shape.
6. Play does not enter protected proof.
7. The design remains recognizably FORGE without its image.
8. The design does not copy a supplied reference.
