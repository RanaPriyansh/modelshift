# Pri Taste Profile for Semester Desk v2

## Purpose and evidence boundary

This profile converts the taste set into rules for Semester Desk v2.
It is a design direction. It is not a copy specification or a production claim.

Use the source set as a system of principles. Do not copy one reference, scene, layout, or headline.
Make a new FORGE world that serves study work and student control.

Primary evidence is `Pri_Visual_Taste_Profile.md`, `catalog.json`, `dominant_palette.jpg`, and `dominant_palette.txt`.
The evidence set contains 34 image files in nine contact sheets.

The source references combine vivid terrain with exact and sparse controls.
The strongest synthesis is `IMG_1398.JPG`, `IMG_1416.JPG`, `IMG_1417.JPG`, `IMG_1422.JPG`, and `IMG_1424.JPG`.

## Design read

Semester Desk v2 is a calm, student-controlled study workspace.
It needs precise planning, readable evidence, and stable navigation.

Apply this product rule without exception:

> **Vivid at thresholds. Quiet during work.**

Use art direction to mark entry, return, course change, review, and completion.
Keep the active desk, task list, evidence view, and edit states quiet.

The source supports this split. `IMG_1139.JPG` places a real work surface inside a large scene.
`IMG_1417.JPG` and `IMG_1418.JPG` keep the interface exact while the image carries the atmosphere.

## Visual north star

Make the product feel considered and human without becoming ornamental.
Use one memorable threshold scene and one clear next action.

Use a large visual field, a small landmark or directional cue, and quiet interface chrome.
The landmark can be a path, horizon, light, room, book, or similar FORGE-specific symbol.
Do not reuse a house, boat, mountain, or scene from the source set.

This direction comes from the scale and focal control in `IMG_1394.JPG`, `IMG_1396.JPG`, `IMG_1397.JPG`, `IMG_1400.JPG`, and `IMG_1419.JPG`.

## Typography

Use a composed grotesk as the primary face.
Prefer the current FORGE type system when it has an equivalent role.
Use regular and medium weights more often than extreme weights.

Use sentence case for headings, actions, and navigation.
Use short lines and direct language.
Keep body text comfortable for sustained reading.

Reserve one secondary typographic expression for a threshold only.
An italic serif phrase can add warmth to a welcome or completion state.
Do not use it in task controls, form labels, source evidence, or dense work views.

Use a pixel or condensed face only for a named, concept-specific feature.
Do not make it a Semester Desk default.

The sans-first direction is supported by `IMG_1408.JPG`, `IMG_1409.JPG`, `IMG_1417.JPG`, and `IMG_1421.JPG`.
The rare serif exception is supported by `IMG_1422.JPG` and `IMG_1424.JPG`.
The pixel exception is supported by `IMG_1411.JPG`.

## Scale and hierarchy

Use scale to show the current study context before secondary data.
The current course, current task, and next decision must be clear in one view.

Use one large heading for a threshold or a new study phase.
Use a smaller, stable heading in the active desk.
Do not use large display type for every panel.

Give the primary action visual priority through position, contrast, and clear wording.
Do not create multiple actions that appear equally urgent.

This use of controlled scale follows `IMG_1136.JPG`, `IMG_1398.JPG`, `IMG_1408.JPG`, `IMG_1409.JPG`, and `IMG_1417.JPG`.

## Rhythm, density, whitespace, and grid

Use a strict grid under expressive threshold art.
Align headings, task controls, source details, and evidence status to repeated columns.

Keep broad whitespace around threshold copy and course transitions.
Reduce spacing only where the student must compare dates, tasks, or source details.

Treat the desk as a daily workspace, not an art gallery.
Use moderate density with clear groups and predictable scan paths.
Do not create an empty desk that hides useful context.

Use rhythm from vertical spacing, type changes, and restrained dividers.
Do not use many panels to create rhythm.

The exact grid with expansive empty space appears in `IMG_1139.JPG`, `IMG_1417.JPG`, `IMG_1419.JPG`, and `IMG_1421.JPG`.
The compact but clear product surface in `IMG_1139.JPG` supports a denser work mode.

## Navigation and information architecture

Keep the primary navigation stable and small.
Show location, current course, current term, and available next action without a navigation maze.

Use one persistent location model across the desk.
Do not hide essential course, task, source, or review state behind decorative controls.

Use direct labels. Prefer `Plan`, `Study`, `Evidence`, and `Review` when they match the product model.
Do not use poetic labels that obscure student actions.

Let a student control movement between work states.
Do not automatically advance, reorder work without explanation, or create pressure with streaks and countdown effects.

Sparse navigation and a visible primary action are supported by `IMG_1137.JPG`, `IMG_1139.JPG`, `IMG_1417.JPG`, and `IMG_1422.JPG`.

## Surface depth, borders, radius, and cards

Create depth with hierarchy, tone, spacing, and one precise border.
Use shadows only when a layer must float above another layer.

Keep working surfaces mostly flat and quiet.
Use a raised layer for a dialog, a temporary course selector, or a threshold action only.

Use a small, consistent radius scale.
Use a larger radius only where a control has a clear interactive role.
Do not round every container, row, icon, and badge.

Do not make a card for each task fact.
Use grouping, headings, spacing, and restrained dividers before cards.
Use a card only when it contains a complete decision, temporary focus state, or protected evidence unit.

This restrained depth appears in the framed surfaces of `IMG_1139.JPG`, `IMG_1416.JPG`, `IMG_1417.JPG`, and `IMG_1418.JPG`.
The source does not support card soup or continuous floating panels.

## Colour, contrast, dark and light, and accents

Use cool atmospheric colours as the FORGE visual base.
The primary source palette includes deep green `#0C140D`, forest `#2A432D`, cobalt `#0A40BB`, and deep blue `#0A3275`.

Use cool ivory `#E0E7EE` and lavender grey `#AFAFC1` for quiet structural surfaces.
Use these colours as a family, not as a generic blue-purple gradient.

Reserve a warm accent for an intentional threshold or commitment.
The source palette supports coral `#CC5D4F`, vermilion `#A7171B`, and antique gold `#B4A871`.

Keep orange for commitment, blue for disclosed AI contribution, and green for tested or reviewed evidence.
Always pair colour with text, shape, and an accessible label.

Make the active desk light by default when this improves long study sessions.
Use dark mode for a threshold, a focused evening context, or an explicit user choice.
Do not flip between light and dark surfaces inside one quiet task flow.

Test every text, icon, control, focus, disabled, and status pair at the implemented size.
Do not place low-contrast copy over terrain or grain.
Add a solid or translucent support surface when image copy needs it.

The cool palette and scarce warm signal are visible in `IMG_1398.JPG`, `IMG_1400.JPG`, `IMG_1401.JPG`, `IMG_1402.JPG`, and `IMG_1420.JPG`.
The light editorial work frame appears in `IMG_1417.JPG` through `IMG_1421.JPG`.
The calm dark threshold appears in `IMG_1399.JPG` and `IMG_1423.JPG`.

## Iconography

Use one geometric icon family with a consistent stroke and size.
Use icons to support a clear label, not to replace a student-facing word.

Keep icons small and quiet in work views.
Use a distinctive icon only for a durable FORGE concept, such as source status or assistance disclosure.

Do not use decorative sparkles, random symbols, emoji, or mixed icon styles.
The source gives limited direct icon evidence, but its sparse controls support a low-icon system in `IMG_1139.JPG`, `IMG_1416.JPG`, and `IMG_1417.JPG`.

## Imagery and texture

Use imagery for threshold moments, not as continuous desk wallpaper.
Make each FORGE scene concept-specific and useful to the study moment.

Use a new terrain, horizon, path, light, archive, or evidence-world metaphor.
Keep a large calm area for text and controls.
Use one small directional landmark when it helps the student understand progress or return.

Use grain, halftone, dither, film softness, or engraved texture with restraint.
Apply texture inside an image asset or a static threshold layer.
Do not place a moving noise layer over work text, controls, or evidence.

Do not use stock team photographs, generic AI brains, chrome robots, neon grids, or unrelated 3D objects.
Do not make the scene look like a game splash screen.

The terrain system is supported by `IMG_1394.JPG`, `IMG_1396.JPG`, `IMG_1397.JPG`, `IMG_1404.JPG`, `IMG_1419.JPG`, and `IMG_1424.JPG`.
The material treatment is supported by `IMG_1395.JPG`, `IMG_1405.JPG`, `IMG_1406.JPG`, `IMG_1407.JPG`, and `IMG_1418.JPG`.

## Motion

Use motion to explain a change of state, a reveal, or a successful completion.
Keep motion slow, short, and optional.

Prefer a single fade, crop, or gentle position transition at a threshold.
Keep task editing, source review, and course navigation instant or nearly instant.

Respect reduced-motion preferences.
Do not use parallax during reading, automatic float effects, animated gradients, bounce, or gamified celebration loops.

The source uses calm atmospheric scenes and restrained interaction shells in `IMG_1137.JPG`, `IMG_1416.JPG`, `IMG_1417.JPG`, and `IMG_1424.JPG`.
The source gives no motion proof. Treat this as a conservative product rule.

## Semester Desk v2 application

### Thresholds

Use a complete visual scene for welcome, return after absence, course change, major review, and meaningful completion.
Show one short message and one clear next action.
Keep a reliable route back to the desk.

Use a new FORGE scene. Do not recreate the frame or layout of `IMG_1398.JPG` or `IMG_1417.JPG`.

### Active desk

Use an ivory or quiet neutral surface, ink text, a stable course context, and a visible task sequence.
Show source state, assistance state, and evidence state in direct language.
Keep the student task as the visual centre.

Use blue only for disclosed AI contribution.
Use green only for a tested or reviewed evidence state.
Use orange only for a deliberate commitment or confirm action.

### Task detail and evidence

Keep source, due information, dependencies, notes, and next action in a clear order.
Use a single focused region for task work.
Avoid a dashboard of competing analytics or progress graphics.

Use accessible status text and a non-colour cue for all evidence states.
Do not make evidence look complete when its source or review state is unknown.

### Completion and review

Make completion feel meaningful through a restrained scene shift or a quiet confirmation.
Do not use confetti, score theatrics, or automatic pressure to start another item.

The contrast between cinematic threshold and quiet work is supported by `IMG_1139.JPG`, `IMG_1416.JPG`, `IMG_1417.JPG`, and `IMG_1422.JPG`.

## Emotional qualities

The intended feeling is calm capability, curiosity, trust, and student agency.
The desk should feel alive at meaningful boundaries and almost invisible during sustained work.

Use optimism without false certainty.
Use play to discover a non-obvious scene, then remove all non-essential controls.

Do not make the student feel managed by an opaque system.
Make state, source, assistance, and next action legible.

These qualities are supported by the scale and solitude in `IMG_1394.JPG`, `IMG_1396.JPG`, `IMG_1422.JPG`, and `IMG_1423.JPG`.
The light experimentation cue is `IMG_1412.JPG`.

## Intelligent, cheap, and generic signals

### Intelligent

An intelligent surface makes the current study situation easy to understand.
It uses one clear next action, reliable location, readable evidence, and restrained visual hierarchy.
It makes an assistance contribution visible instead of pretending that assistance is invisible.

It shows a distinctive FORGE scene at a meaningful threshold, then gets out of the way.
This balance is supported by `IMG_1139.JPG`, `IMG_1416.JPG`, and `IMG_1417.JPG`.

### Cheap

A cheap surface uses decoration to hide unclear information architecture.
Signals include multiple gradient panels, glossy glass everywhere, noisy shadows, random 3D shapes, and too many status pills.

It also includes low-contrast image copy, generic purple-blue effects, or vivid art behind every desk operation.
These failure modes conflict with the control shown in `IMG_1398.JPG`, `IMG_1403.JPG`, `IMG_1417.JPG`, and `IMG_1421.JPG`.

### Generic

A generic surface could belong to any study app.
Signals include identical card grids, stock education imagery, dashboard metrics with no student decision, and unexplained gamification.

Generic work also copies a single reference instead of extracting its principles.
The source repeats a stable visual grammar across `IMG_1398.JPG` through `IMG_1402.JPG` and `IMG_1417.JPG` through `IMG_1421.JPG`.

## Likely rejection criteria

Reject a proposal when it has any of these conditions:

- It uses vivid scenery behind active study work. Evidence: `IMG_1139.JPG`, `IMG_1417.JPG`.
- It copies a source composition, image, headline, or landmark. Evidence: the repeated but varied systems in `IMG_1398.JPG` through `IMG_1402.JPG`.
- It adds a card, pill, badge, or shadow without a clear hierarchy purpose. Evidence: `IMG_1139.JPG`, `IMG_1417.JPG`, `IMG_1421.JPG`.
- It uses a generic purple gradient, cyberpunk black dashboard, robot, or stock education image. Evidence: the distinct visual worlds in `IMG_1403.JPG`, `IMG_1416.JPG`, and `IMG_1424.JPG`.
- It makes course, task, source, assistance, or review state hard to understand. Evidence: the sparse but clear product frame in `IMG_1139.JPG` and `IMG_1416.JPG`.
- It makes the student act automatically or through pressure. This conflicts with the required student-controlled Semester Desk v2 model.
- It relies on colour alone, low contrast, or unreadable text over imagery. Evidence: the clear text fields in `IMG_1398.JPG`, `IMG_1417.JPG`, and `IMG_1423.JPG`.
- It uses constant motion, bounce, noise, or animated effects in a focused work state. Evidence: the calm stillness of `IMG_1418.JPG`, `IMG_1422.JPG`, and `IMG_1424.JPG`.
- It makes FORGE feel like a generic component library or a luxury lifestyle product. Evidence: `IMG_1405.JPG`, `IMG_1406.JPG`, `IMG_1416.JPG`, and `IMG_1417.JPG`.

## Review checklist

- Does the surface make the current student decision clear before decorative details?
- Does the active desk stay quiet and readable for sustained work?
- Does a threshold have one new FORGE-specific visual idea, not a copied reference?
- Do colour, shape, text, and iconography all communicate status together?
- Does the student retain control over start, continuation, review, and movement?
- Are contrast, focus, reduced motion, and text readability checked in the implemented interface?
- Did the implementation avoid card soup, generic gradients, omnipresent glass, and dashboard noise?
